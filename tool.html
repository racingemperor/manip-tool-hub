Input Parameters

A ToolUniverse-style contract for repository-relative local usage. This static page documents the fields; it does not execute them.

imagerelative path | filerequired

Project-relative image or scene path to run open-vocabulary detection on.

promptsstring | string[]required

Object vocabulary to detect, such as person,bus,car or robot arm,gripper,red cube.

thresholdnumberoptional

Confidence threshold. Lower values show more candidates; higher values return fewer, stronger detections.

topkintegeroptional

Maximum number of candidate detections to keep after inference.
