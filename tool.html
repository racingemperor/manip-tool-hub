API

Use this area for a local wrapper, hosted endpoint, or future service interface.

POST /api/tools/yolo-world/detect
Content-Type: multipart/form-data

image=@scene.jpg
prompts=person,bus,car
threshold=0.05

Request fields:
- image: file | URL
- prompts: comma-separated text categories
- threshold: confidence threshold
- topk: max detections to return
- return_visualization: include rendered result image

Response:
- detections: array of boxes, labels, scores
- visualization: optional artifact URL
- timing: optional runtime breakdown
